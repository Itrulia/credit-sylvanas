# Repo map

A single package. This is the planned layout; build it this way and update
this file when it changes.

| Path | Contains |
| --- | --- |
| `src/routes/` | File-based routes. `__root.tsx` is the shell: head, theme, the TSM credit and the "not affiliated" footer. Loaders call server fns; search params are validated with zod. |
| `src/routeTree.gen.ts` | Generated by the router plugin. Never edit. |
| `src/server/` | Server-only code. `db` opens `node:sqlite` and holds schema and queries, `ingest` fetches TSM CSVs, validates the header and upserts snapshots, plus the server fns (`createServerFn` with zod input). |
| `src/server/__fixtures__/` | Tiny real TSM CSV samples, for tests only. |
| `src/config/realms.ts` | The one typed realm list (`{ region, slug, name, ruleset }`). It ships empty because Forever realm names are unknown. |
| `src/components/ui/` | shadcn components, managed by the CLI. |
| `src/components/` | App components built from `ui/`. |
| `src/lib/` | Isomorphic helpers (`cn`, copper formatting, Wowhead URLs). Nothing here may import from `src/server`. |
| `src/styles.css` | Tailwind and theme tokens. Brand colours: oatmilk `#EDE4D3`, forest `#1D4A35`, tomato `#F2462E`. |
| `data/` | The SQLite DB (`DATABASE_PATH`, default `./data/prices.db`). Gitignored. |
| `docs/` | Product docs: `CONTEXT.md` (ground truth) and `DESIGN.md`. |

## The server/client boundary

Route components and `src/lib` reach `src/server` only through a
`createServerFn` call. Never import `#/server/db`, or anything else that pulls
in `node:sqlite`, from a component, a route's component code or `src/lib`.
Write route-level `server: { handlers }` blocks literally inside the
`createFileRoute` call ([gotchas.md](gotchas.md)). `pnpm build` is the check.

## Where to start

| Task | Start here |
| --- | --- |
| New price view | `src/routes/...` plus a server fn in `src/server` |
| New CSV column or TSM format change | the header schema in `src/server/ingest`, a fixture and a spec |
| New table or column | the schema in `src/server/db`, with a migration step for existing DBs |
| Add a realm | `src/config/realms.ts` |
